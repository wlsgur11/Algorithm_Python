### 문제 설명
<p>스페이스로 띄어쓰기 된 단어들의 리스트가 주어질 때, 단어들을 반대 순서로 뒤집어라.</p><p>각 라인은 w개의 영단어로 이루어져 있으며, 총 L개의 알파벳을 가진다.</p><p>각 행은 알파벳과 스페이스로만 이루어져 있다.</p><p>단어 사이에는 하나의 스페이스만 들어간다.</p>

### 입력
<p>첫 행은 N이며, 전체 케이스의 개수이다.</p><p>N개의 케이스들이 이어지는데, 각 케이스는 스페이스로 띄어진 단어들이다.</p><p>스페이스는 라인의 처음과 끝에는 나타나지 않는다. N과 L은 다음 범위를 가진다.</p><ul><li>N= 5</li><li>1 ≤L≤ 25</li></ul>

### 출력
<p>각 케이스에 대해서, 케이스 번호가 x일 때,</p><p>&quot;Case #x: &quot; 를 출력한 후 그 후에 이어서 단어들을 반대 순서로 출력한다.<br />(단, 각 출력의 끝은 개행으로 한다.)</p>

### 예제 입력/출력
**예제 입력 1**
```
3
this is a test
foobar
all your base
```
**예제 출력 1**
```
Case #1: test a is this
Case #2: foobar
Case #3: base your all
```
